# SC-001 parity status

The [baseline](baseline-report.md) passed 121 comparisons on seven fits
using Pyfa v2.70.0 and aligned CCP build 3724492. The tests distinguish
zero, an applicable measured value and a non-applicable measurement.

The release corpus still needs the required 30 or more fits with
verified coverage for strategic cruisers, structure modules, custom
skills, overheating, implants and boosters, Abyssal behavior, and
external command and projected effects. It also needs reference
control points for the damage and capacitor graphs. The current
application exposes the damage-by-distance graph and identifies the
capacitor timeline as unavailable.
